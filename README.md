🔥 Tactical Strike – Counter-Strike on Android

A standalone Android Counter-Strike experience powered by Xash3D FWGS.

مشروع Tactical Strike يهدف إلى تقديم تجربة Counter-Strike 1.6 على أجهزة Android، مع تشغيل سلس وتحكم باللمس وإمكانية اللعب الجماعي عبر الإنترنت.

🎮 Features | المميزات

- تشغيل Counter-Strike 1.6 على Android.
- محرك Xash3D FWGS.
- دعم معمارية ARM.
- تحكم مخصص للشاشات اللمسية.
- إمكانية اللعب الجماعي عبر الإنترنت.
- مشروع قابل للتطوير والتحسين.

📱 About the Project | عن المشروع

تم تطوير هذا المشروع بهدف توفير تجربة Counter-Strike على الهواتف، مع العمل على دمج المحرك وعميل اللعبة ضمن تطبيق Android مستقل.
